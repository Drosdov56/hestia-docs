# UI-002

Statut : À démarrer

Dépendance :
- UI-001 terminé (VALIDÉ AVEC RÉSERVES)

---

## Origine

UI-002 est issu du Tech Committee de clôture de UI-001.

Les réserves validées ont été transformées en backlog de consolidation ergonomique.

UI-001 demeure définitivement clos.

Aucune réouverture de UI-001 n'est prévue, sauf anomalie critique.

---

## Objectif

Poursuivre l'amélioration ergonomique de l'administration des nœuds sans modifier :

- API
- endpoints
- permissions
- logique métier
- ADR-021
- ADR-023

Le comportement fonctionnel de UI-001 constitue la référence.

---

## Lots prévus

### UI-002-A

Consolidation ergonomique du Parc

- alléger la densité visuelle ;
- supprimer les redondances ;
- simplifier les liens de navigation.

Priorité : Haute

---

### UI-002-B

Observabilité lisible

- dates formatées ;
- JSON repliable ;
- amélioration de la lisibilité du Diagnostic.

Priorité : Haute

---

### UI-002-C

Accessibilité

- navigation clavier ;
- amélioration ARIA des onglets.

Priorité : Moyenne

---

### UI-002-D

Hygiène CSS / JS

- suppression de code mort ;
- factorisation légère ;
- helpers communs locaux.

Priorité : Basse

---

## Hors périmètre

Ne pas traiter :

- nouveaux endpoints ;
- nouveaux indicateurs ;
- nouvelles actions ;
- refactoring global ;
- découpage complet de nodes.js.

Ces éléments ont été rejetés ou reportés par le Tech Committee.

---

## Gouvernance

Chaque lot UI-002 devra :

- être indépendant ;
- faire l'objet d'un commit dédié ;
- pouvoir être validé séparément.

La clôture documentaire sera réalisée à la fin du chantier UI-002.

---

## Critères de clôture

UI-002 devra :

- conserver le comportement métier de UI-001 ;
- réduire la dette ergonomique identifiée ;
- maintenir la stabilité fonctionnelle ;
- rester constitué de petits lots indépendants.
